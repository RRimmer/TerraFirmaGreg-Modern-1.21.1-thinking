# TerraFirmaCraft Modern 1.21.1

This is not a modpack. It is a personal note.

I am looking through mods I care about and asking a simple question: can their original authors move them to Minecraft **1.21.1**? The page is where I write down what I find, plus a few thoughts. It is not a release plan and not an official TerraFirmaCraft project.

Open [`index.html`](index.html).

## Where I look

1. **CurseForge.** The usual project pages.
2. **GitHub.** Often the newer builds, unofficial ports, and forks.
3. **Modrinth.** Only if the mod is not on the other two.

Checked on **24 September 2026**. The list has **275** names.

| Status | Count | Meaning |
| --- | ---: | --- |
| On 1.21.1 | 223 | A build for 1.21.1 showed up |
| Port or different name | 3 | A 1.21.1 build exists under another name, as a port or a lite edition |
| Older only | 40 | The project exists, but not for 1.21.1 |
| Not found | 6 | I have not found it yet |
| Uncertain | 3 | The closest hit was a different project, so I did not count it |

An earlier draft said the search had "landed on someone else's addon." That only meant the first name match was a different project, so I refused to count it as the mod I was looking for. Several of those rows were mistakes and are corrected on the page.

One thing that stood out: on 1.21.1 most mods have already moved to NeoForge. APTweaks still has a 1.21.1 file, and that file is Forge.

### Где я смотрю

1. **CurseForge.** Обычные страницы модов.
2. **GitHub.** Чаще свежие сборки, неофициальные порты и форки.
3. **Modrinth.** Только если на первых двух пусто.

Проверка от **24 сентября 2026**. В списке **275** названий.

| Статус | Количество | Смысл |
| --- | ---: | --- |
| Есть на 1.21.1 | 223 | Сборка для 1.21.1 нашлась |
| Порт или другое имя | 3 | Сборка 1.21.1 есть, но под другим именем, как порт или урезанная версия |
| Только старее | 40 | Проект есть, но не для 1.21.1 |
| Не найдено | 6 | Пока не нашёл |
| Сомнительно | 3 | Ближайшее совпадение было другим проектом, поэтому я его не засчитал |

Фраза «поиск попал в чужой аддон» значила только это: первое совпадение по имени было другим проектом, и я не стал считать его за нужный мод. Часть таких строк оказалась ошибкой, на странице они исправлены.

Отдельно бросилось в глаза: на 1.21.1 большинство модов уже на NeoForge. У APTweaks файл 1.21.1 есть, и он всё ещё Forge.
