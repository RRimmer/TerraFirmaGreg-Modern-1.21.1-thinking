# TerraFirmaGreg-Modern 1.21.1

This is not a modpack. It is a personal note.

I am looking at the mods from the original **TerraFirmaGreg-Modern** list and asking whether their authors can move them to Minecraft **1.21.1**. The page is where I write down what I find. Mods I had added for myself are not in this list.

Open [`index.html`](index.html).

## Where I look

1. **CurseForge.** The usual project pages.
2. **GitHub.** Often the newer builds, unofficial ports, and forks.
3. **Modrinth.** Only if the mod is not on the other two.

Checked on **24 September 2026** against the TerraFirmaGreg-Modern 1.20.1 mod list. **265** mods from that list.

| Status | Count | Meaning |
| --- | ---: | --- |
| On 1.21.1 | 218 | A build for 1.21.1 showed up |
| Port or different name | 4 | A 1.21.1 build exists under another name, as a port or a lite edition |
| Older only | 43 | The project exists, but not for 1.21.1 |
| Not found | 0 | I have not found it yet |
| Uncertain | 0 | The closest hit was a different project, so I did not count it |

On 1.21.1 most of these mods have already moved to NeoForge. APTweaks still has a 1.21.1 file, and that file is Forge.

The original list is the TerraFirmaGreg-Modern pack by Exception and Xikaro (`TerraFirmaGreg-Team/Modpack-Modern`).
