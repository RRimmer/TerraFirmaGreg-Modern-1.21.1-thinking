# TerraFirmaCraft Modern 1.21.1

A working catalog of mods from a TerraFirmaCraft Modern pack list, checked against CurseForge for Minecraft **1.21.1**.

Open [`index.html`](index.html) in a browser. It is a single static page: search, filters, and links to the matching CurseForge projects.

This repository is not an official TerraFirmaCraft, TerraFirmaGreg, or CurseForge project. It is a porting checklist.

## What the numbers mean

Checked on **24 September 2026** with CurseForge mod search filtered to Minecraft 1.21.1. The list has **275** mods.

| Status | Count | Meaning |
| --- | ---: | --- |
| On 1.21.1 | 205 | A project with the same name appears in the 1.21.1 search |
| Port or different name | 7 | A 1.21.1 build exists, but as a port, lite edition, or renamed project |
| Older versions only | 33 | The project exists on CurseForge, with no 1.21.1 file in that search |
| Not found | 16 | No matching CurseForge project |
| Uncertain match | 14 | Search opened an addon or a different mod. These are not counted as available. The page note says which project opened |

TerraFirmaCraft itself has a NeoForge build for 1.21.1 (`1.21.1-4.2.10` at the time of the check). Examples that were on 1.21.1: FirmaLife, Beneath, ArborFirmaCraft, Roads and Roofs TFC, KubeJS TFC. Examples that were not: Firma: Civilization, Epic Knights of TerraFirma, TerraFirmaGreg-Core, Create: Steam 'n' Rails.

Names can collide. A row is marked uncertain when the first hit was clearly a companion mod rather than the mod from the list.

## Русский

Рабочий каталог модов из списка сборки TerraFirmaCraft Modern. Каждый мод сверен с CurseForge на наличие версии Minecraft **1.21.1**.

Откройте [`index.html`](index.html) в браузере. Это одна статическая страница: поиск, фильтры и ссылки на проекты CurseForge.

Репозиторий не является официальным проектом TerraFirmaCraft, TerraFirmaGreg или CurseForge. Это список для переноса сборки.

### Что означают цифры

Проверка от **24 сентября 2026**. Поиск модов на CurseForge с фильтром версии 1.21.1. В списке **275** модов.

| Статус | Количество | Смысл |
| --- | ---: | --- |
| Есть на 1.21.1 | 205 | В поиске с фильтром 1.21.1 есть проект с тем же именем |
| Порт или другое имя | 7 | Сборка на 1.21.1 есть, но это порт, урезанная версия или проект под другим названием |
| Только старее | 33 | Проект на CurseForge есть, файла 1.21.1 в этом поиске нет |
| Не найдено | 16 | Подходящий проект на CurseForge не найден |
| Сомнительное совпадение | 14 | Поиск открыл аддон или другой мод. Такие строки не считаются доступными. В примечании указано, какой проект открылся |

У самой TerraFirmaCraft на момент проверки уже был файл NeoForge для 1.21.1 (`1.21.1-4.2.10`). На 1.21.1 были, например, FirmaLife, Beneath, ArborFirmaCraft, Roads and Roofs TFC и KubeJS TFC. Без файлов 1.21.1 оставались Firma: Civilization, Epic Knights of TerraFirma, TerraFirmaGreg-Core и Create: Steam 'n' Rails.

Одинаковые названия путаются. Строка помечена как сомнительная, если первым результатом был явно чужой аддон, а не мод из списка.
